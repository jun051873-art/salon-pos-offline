# 專屬空間沙龍 POS — v33.0.0

入口：https://jun051873-art.github.io/salon-pos-offline/

本次整合開單入帳、改單差額收退、儲值本金／贈送金、VIP 折扣、成本損益、庫存退貨報廢、薪資、個人操作權限及加密備份。店用雲端專案不在此專案範圍。

## 操作入口

- **VIP 與儲值**：儲值收款、退本金、贈送金及完整異動紀錄。VIP 門檻與優惠在店家設定。
- **查單管理**：修改價格後明確顯示待補收／待退差額，完成實際付款後再登記；儲值單由退款入口退回原餘額。
- **營運報表 → 損益與現金流**：分開營收、成本、應計薪資與實際收付款。儲值收款不列營收，借支、薪資付款及進貨不重複扣成本。
- **人員管理 → 薪酬設定**：店家／個人／單項抽成、販賣獎金、月底薪或時薪；薪資條處理預支、領料、加扣項、付款及更正。
- **店家設定 → 權限**：店主 PIN、員工功能權限、閒置鎖定、操作紀錄。指定對應人員並授予「查看自己的薪資」，可僅查看本人薪資。
- **店家設定 → 個人雲端**：AES-GCM 加密後寫入個人同步資料夾，或 Google Drive。每次保存新版本；失敗不標記成功，資料異動自動重試。

## 個人備份連線

同步資料夾模式需先在電腦安裝並登入自己的雲端同步軟體，再選擇該資料夾。程式驗證本機檔案寫入，實際雲端同步由該軟體完成。Google Drive 直接模式需網站 OAuth 用戶端 ID 與使用者本人授權，僅使用 drive.file 範圍。密碼與 token 不存進業務資料或來源碼；工作階段結束後需重新連接。備份運作於頁面開啟期間，不是伺服器排程，也不是多裝置即時合併。

還原時選加密 JSON，輸入密碼。先驗證儲值、單據、薪資、退款關聯，並保存還原前副本；舊檔衝突須明確輸入覆蓋確認。密碼遺失無法解密。

## 儲存及權限範圍

業務資料以一筆完整記錄原子寫入 localStorage；Web Locks 限制單一寫入視窗。儲存失敗不清空原資料。PIN 是同裝置操作控制，不能防止裝置管理者透過開發者工具讀取本機資料。正式多租戶伺服器權限及商店包不是此靜態網站的部署形態。

## 建置及測試

```sh
npm ci
npm run build
npm test
```

`app.jsx` 是畫面與帳務流程，`business-store.js` 是原子儲存層，`commerce-core.js` 是儲值／損益，`access-core.js` 是操作權限，`backup-cloud.js` 是加密及備份。`index.html` 是建置後可部署檔。

自動測試使用合成資料；私人舊備份測試需 `SALON_BACKUP_FIXTURE`，沒有私人檔案時會跳過。Google 真實帳號授權及雲端同步不能以模擬測試冒充已完成。詳見 [v33 驗證紀錄](REVIEW-v33.0.md)。
